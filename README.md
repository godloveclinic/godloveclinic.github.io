# 主愛心靈診所 官方網站

主愛心靈診所（身心科）與附設主愛心理諮商室的官方網站。

- 多頁式網站：首頁 `index.html`，以及 `about`（關於我們）、`services`（服務項目）、`team`（醫療團隊）、`schedule`（門診時間）、`first`（門診流程）、`check`（心情檢測）、`faq`（常見問題）、`contact`（交通資訊）各一頁
- 共用檔案：`style.css`（樣式）、`site.js`（腳本）、`images/`（醫師與心理師照片）、`godlove-logo.png`（LOGO）、`fonts/`（字體）
- 門診時間、醫師排班集中在 `site.js` 最上方的 `SESSIONS` 與 `WEEK`，修改該處即可
- 門診皆為現場掛號，不提供線上預約
- `sitemap.xml` 列出所有頁面；`google508ec328890be3f5.html` 是 Google 網站驗證檔，請勿刪除
